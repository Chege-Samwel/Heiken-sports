Reference

API Response Formats

The API returns two different JSON formats depending on the sport. All other fields are identical — the only difference is how the event participants are represented.

Key Differences

  • Team vs Team format uses homeTeam, awayTeam, homeTeamIMG, awayTeamIMG
  • Event-Based format uses event and eventIMG instead (no team fields)
  • Shared all other fields (gameID, time, tournament, country, status, start, end, channels) are identical in both formats

Note: Event-based responses have no homeTeam, awayTeam, homeTeamIMG, or awayTeamIMG fields. Instead, the event name and image are in event and eventIMG.
